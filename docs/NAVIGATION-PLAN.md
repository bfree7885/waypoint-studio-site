# Waypoint Studio — Navigation Plan

**Sprint:** RC3 Sprint 1

---

## Primary navigation

Clean, intentional, consistent across marketing pages:

1. **Dashboard** → `/dashboard/`
2. **Scenes** → `/waypoint-scenes/`
3. **Sheds** → `/sheds/`
4. **Volunteer** → `/volunteer/`
5. **Articles** → `/education/`
6. **About** → `/about/`

Home uses the brand mark; product apps (Sheds, Volunteer) may keep slim field bars with a Waypoint home link.

### Unobtrusive Incubator

- Linked from homepage (secondary), About, footer, and `/incubator/`
- Not required in the primary six-item nav on every page
- Optional quiet footer link: Incubator

---

## Information architecture

```
Home
├── Dashboard (free mission control)
├── Scenes (flagship photography)
├── Sheds (flagship shed hunting)
├── Volunteer (free stewardship)
├── Articles (platform education)
├── About
├── Incubator (future products)
├── Privacy / Contact / Support
└── Supporting (secondary)
    ├── ForageCast
    ├── Fieldry
    ├── Gallery / Workshop / Projects archive
    └── Knowledge graph docs
```

---

## Rules

- Prefer one path to each primary product.
- Do not list ForageCast or Fieldry in primary nav.
- Label Scenes as “Scenes” even when the folder remains `waypoint-scenes/`.
- Education is presented as **Articles**.
- App shells may use product-local nav (Saved, About sheet) without duplicating the full marketing nav.
